# theme-mudanzas adoption

This repository consumes the canonical `theme-mudanzas` contract defined by the Mudanzas ecosystem.

## Product role
Commercial/provider layer: communicate the real company, services, evidence, coverage and quotation path.

## Adoption boundary
Shared layout primitives may converge. Provider brand expression, commercial content, routes, SEO/entity data, forms and conversion logic remain local.

## QA
Any change that alters rendered UI requires automated technical QA first and a UI/UX HUMAN GATE only after technical PASS.
